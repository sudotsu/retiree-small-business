# README — Module 1: Knowing Yourself

**Retiree Business Blueprint | Mastery Track**

---

**lesson_1.1.md through lesson_1.5.md** are the five student-facing lesson pages for Week 1. All five were rebuilt to current production standards — AI artifact headings removed, copy-paste artifacts from the source PDFs removed, emojis removed, heading hierarchy corrected, quiz and checklist formats standardized, and time estimates corrected to reflect actual content (Lesson 1.3 is ~85–90 min; the rest range from ~70–80 min). The progression across the five lessons is: decision drivers (1.1) → default settings map (1.2) → plus/minus analysis (1.3) → rewrite and guardrails (1.4) → fit check and decision gate (1.5).

**module_1_workbook.md** compiles all exercises from lessons 1.1 through 1.5 into a single printable document. There is a legacy PDF (`Module-1_Workbook.pdf`) from the earlier production phase — the .md file is the current source.

**Module_1_Student_Facing.md** is the landing page students see when they begin Week 1. It summarizes what the module covers, lists all five lessons with time estimates, notes that Lesson 1.3 is the longest session (four Plus/Minus tables), and provides support contact placeholders. Those placeholders need current values before publishing.

**module_1_instructor_guide.md** covers facilitation notes for all five lessons, the most common student patterns Chaz is likely to see each day (students who mark everything "Helps me," students who rate themselves Green out of optimism rather than honesty, students who cannot identify flip conditions), and notes on the Lesson 1.5 community thread as a diagnostic tool for the cohort's overall readiness.

**module_1_learndash_plugin.md** is the full LearnDash configuration reference for this module. It was rebuilt from the original 50-line emoji-heavy summary into a complete spec covering prerequisite chain, quiz configuration, workbook attachment, accessibility checklist, and community thread setup. It references `module_2_learndash_plugin.md` as the master quiz settings document.

**module_1_status.md** is the production checklist — file inventory, a record of the prior production issues that were corrected during the rebuild, content review items, LearnDash config items, accessibility, and publishing steps.

**README_for_chaz.md** is this file. **READ-THIS-FIRST.md** is the quick-reference navigation table for the folder.
