# README — Module 0: Welcome and Orientation

**Retiree Business Blueprint | Mastery Track**

---

**lesson_0.1.md** and **lesson_0.2.md** are the two student-facing lesson pages. They contain all reading content, exercises, journal prompts, community prompts, and mini-quizzes for the orientation week. Both were rebuilt to current production standards — no emojis, correct heading hierarchy, content-based time estimates (~60–70 min and ~70–75 min). Lesson 0.1 covers track selection, schedule setup, and workspace. Lesson 0.2 covers the Belief Inventory and the Second-Act Declaration.

**module_0_workbook.md** compiles all exercises from both lessons into a single printable document. This is the source file for the PDF students download before Lesson 0.1. There is also a legacy PDF (`Module-0_Workbook.pdf`) from an earlier production phase — the .md file is the current source. The standard print settings for all workbooks are in `module_0_learndash_plugin.md`.

**Module_0_Student_Facing.md** is the landing page students see immediately after enrolling. It displays a brief welcome, workbook download link, support contact, and the Start Lesson 0.1 button. The contact information fields are placeholders — they need current values before publishing.

**module_0_instructor_guide.md** covers facilitation notes for both lessons: the common student patterns Chaz is likely to see (tech anxiety, skipping the workspace exercise, Second-Act Declarations written for an external audience rather than the student), suggested responses for the four most common orientation-week questions, notes on recording a welcome video, and a structural note about the 4-lesson vs. 2-lesson design decision.

**module_0_learndash_plugin.md** is the LearnDash configuration reference for this module. It covers prerequisite chain settings, quiz configuration with a note on pass thresholds for first-time quiz users, workbook attachment, landing page layout, community thread suggestions, and the accessibility checklist specific to Module 0.

**README_for_chaz.md** is this file. **READ-THIS-FIRST.md** is the quick-reference navigation table for the folder.

**module_0_status.md** is the production checklist — file inventory, content review items, LearnDash config items, accessibility, and publishing steps.

---

**Note on source material:** The `Module_0_Welcome_Course_Setup` directory contains the original four-lesson spec (0.1 through 0.4). The current production consolidates those into two fuller lessons. The decision whether to expand back to four shorter lessons is covered in the instructor guide and is open.
