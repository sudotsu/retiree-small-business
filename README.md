## Course Structure

**Mastery Track** — 8 weeks, ~56 hours
Nine modules (0–8), five lessons each. Students work through one module per week at roughly one focused hour per day, five days per week. Two catch-up days are built into each week.

**Essentials Track** — 8 days, ~10 hours
A condensed version covering the same core areas. Designed as a standalone foundation or as a free on-ramp to Mastery. Students who complete Essentials and upgrade to Mastery have their Essentials payment credited — they never pay twice.

**Week 1 is free.** No payment information required. Module 1 (Mastery) or Days 1–8 (Essentials) are accessible without a card capture. This is both a trust signal and a differentiator — documented fully in `marketing/landing-page.md`.

## What Each Module Folder Contains

Every module folder (`module-XX-*/`) has the same structure:

| File | Who it's for | What it is |
|------|-------------|------------|
| `READ-THIS-FIRST.md` | Chas | One-page table: every file, who it's for, what it contains |
| `README_for_chaz.md` | Chas | Paragraph description of every file |
| `Module_X_Student_Facing.md` | Students (via LearnDash) | Module landing page — what the week covers and promises |
| `lesson_X.1.md` – `lesson_X.5.md` | Students | Full lesson content — reading, exercises, mini-story, quiz, checklist |
| `module_X_workbook.md` | Students (print) | All exercises compiled for print, no prose |
| `module_X_instructor_guide.md` | Chas | Recording prep notes, facilitation context, what to watch for |

## Video Scripts

One intro video per module (Modules 0–8), one per Essentials day (Days 1–8), and a course outro. Each comes in two versions:

- **Full narrative** (~920 words, ~7 min for modules / ~590 words, ~4:30 min for Essentials days)
- **Teleprompter** — short lines with pause markers, designed to read aloud naturally on camera

The Module 0 scripts in the SOT have multiple versions (v1, v2, v3). Use `Module_0_Video_Script_v3.md` — it's the final version.

## Launch Infrastructure

See `suggestions-and-roadmap/launch-roadmap.md` for a full ranked list from optional to must-have. The short version of the must-haves: WordPress hosting (WP Engine or Kinsta), domain + SSL, LearnDash, Stripe + PayPal, Wordfence security + 2FA + backups, ConvertKit for email, quiz segmentation via Typeform + Zapier.
